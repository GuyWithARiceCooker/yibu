# Yibu

**A language learning assistant app** — 一步 (*yī bù*, “one step”)

Yibu is a language-learning app that lets you speak freely and practice languages with a personal tutor. Talk anytime — out loud or in writing — about the things you care about, and receive honest, clear corrections that fit the way you learn.

This repository hosts the Hebrew (and multi-language) home page / demo for the Yibu English learning app.

## Features

- Conversational practice with an AI tutor (voice or text)
- Personalized corrections and feedback
- Support for multiple learning languages
- Multi-language interface (English, Hungarian, Chinese, Hebrew, and more)
- Word/phrase collection from your chats
- Dictation and other practice tools

## Preview

Open `index.html` in a browser to see the landing page and interactive demo.
